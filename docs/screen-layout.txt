llm-desk has four full-screen pages: main, vendors, users, and projects.
The main screen (accounts, sessions, notes, and account info) is always one
of the pages; vendors, users, and projects are the others, reached from the
main screen via `v` / `u` / `p` and returned from via `Esc`. All list rows
use a single leading space so text does not touch the panel frame. Detail
rows use a one-cell inset on both sides that also applies to wrapped lines.

── Main screen (accounts, sessions, notes, and account info) ────────────────

┌ llm-desk ───────────────────────────────────────────────────────────────┐
│                                                                         │
│  ┌ Accounts 1/3 ────────────┐  ┌ Sessions 1/5 ───────────────────────┐  │
│  │▶ claude │ Alice │ 18:00  │  │▶ Alpha │ Architecture review│ 2 │   │  │
│  │  chatgpt│ Bob   │ 09:15  │  │  Beta  │ Billing refactor   │ 0 │   │  │
│  │  claude │ Carol │        │  │  Alpha │ Old research       │ 3 │ ✓ │  │
│  └──────────────────────────┘  └─────────────────────────────────────┘  │

Accounts (left) lists every (user, vendor) pair as aligned columns:
vendor, user name, pause time, and latest project, soonest-available
first. Columns are padded and separated by " │ "; blank cells keep their
separator and padding so later columns stay aligned. The pause and project
columns are omitted only when no rendered row has a value. Vendor, user,
and project values are capped and truncated with an ellipsis when needed;
widths come from the values actually rendered. Same-day pause times show as
"HH:MM"; other days as "HH:MM ±N", the number of days from today (for
example, "09:00 +2", "20:00 -1"). Pause time is red while the account is
still unavailable, green once it is available again, and omitted for an
account that has never been paused. Pause status appears only in the
accounts list. The latest project is the project of the account's latest
session when that project is still granted to the account.

Sessions (top right) lists the account's sessions in activity order:
updated-at descending, then ID descending. Each row is one session and
shows the project, session name, prompt count, and status marker. The
project column is hidden when no visible session has a project. The status
marker is a yellow "✓" for needs closing, a gray "✓" for closed, and empty
for active. An empty session name renders as dim "(untitled)". The title
shows the project filter suffix, if any, and the selected row position over
the total displayed row count. The key `f` advances the project filter.

Sessions keys:
- `Enter` opens the prompt editor for the selected session.
- `Ins` starts a new session.
- `Del` deletes the selected session after confirmation.
- `f` advances the project filter.

Notes (below Sessions) lists the notes visible for the account and the
current project filter, ordered by ID ascending. Each row shows the
project, the account's user name, and the first line of the note text.
The account and project columns are removed when the pane is too narrow to
leave at least 12 cells for the text. The title shows the filter suffix, if
any, and the selected note position over the displayed note count.

The full-width Account Details panel below both panels shows the user,
vendor, and granted projects, and grows with wrapped project text. The
latest session's project is highlighted in green when it is still granted.
The Account Details, Vendor Details, and Project Details panels size their
label columns from their own longest labels and grow with their wrapped
content.

Status messages: an inline status such as "saved ✓" is right-aligned. At
the minimum width it is separated from the common hints by two spaces. The
first-run notice and errors use a separate area below the common hints.
Notices are yellow; errors are red and wrap to at most three rows.

── Prompt editor ────────────────────────────────────────────────────────────

Edit mode opens the prompt editor with the session's prompt queue above the
prompt field:

┌ Edit Prompts 1/3 ───────────────────────────────┐
│ Status [Active ▾]                 [Session]     │
│                                                 │
│ ┌ Prompts ────────────────────────────────────┐ │
│ │ 1. continue                                 │ │
│ │ 2. start handover                           │ │
│ │ 3. review billing                           │ │
│ └─────────────────────────────────────────────┘ │
│                                                 │
│ Prompt                                          │
│ [ text area ]                                   │
│ Clear                                           │
│ Copy                                            │
│                                                 │
│          [Save]   [Cancel]   [Delete]           │
└─────────────────────────────────────────────────┘

- The prompt list is shown in Edit mode. It is omitted in Add mode.
- The list shows at most five rows and scrolls beyond that.
- Focus order: Status, Session, list, Clear, Copy, Prompt, Save, Cancel.
- When the list has focus, normal list keys navigate it, `Enter` focuses the
  prompt field, `Ins` adds a prompt, and `Del` removes the selected prompt
  after confirmation.
- The list highlights only when it has focus.
- Save writes the whole prompt list atomically. Cancel discards unsaved edits.
- Add mode appends one prompt and closes on Save.
- The `Delete` button removes the current prompt after confirmation and saves
  immediately. If prompts remain, the next prompt is selected and the editor
  stays open. If the list becomes empty, the editor closes.
- The list `Del` key removes the selected prompt from the open editor, but Save
  is still required.

Dropdowns show a trailing "▾" and size themselves to the longest option,
capped at the normal field width. Longer options are truncated with an
ellipsis.

When a modal opens another modal, the parent remains visible and its border
turns gray. `Esc` closes one modal level and returns to the parent. The top
modal alone receives keyboard and mouse input.

The right side of the body is a column with the Project Accounts list
above the Project Notes list. Both lists have equal height weight and a
minimum height of three rows. The Project Accounts list shows only the
accounts granted the selected project, ordered by vendor and then user
name. The Project Notes list shows every note for the selected project,
ordered by ID ascending; each row shows the account's vendor and user name
and the first line of the note text. Vendor and user cells use the same
" │ " separator and padding as the main accounts list, with the same
single leading space. Insert adds a note to the project; Enter edits the
selected note; Del deletes it after confirmation. Tab moves focus through
Projects, Project Accounts, Project Notes, and back to Projects.
Shift+Tab moves in the reverse order. Esc from any of the three lists
returns to the main screen. There is no start-session key on this screen.
The Project Details panel below grows with wrapped description or
instructions.
